加载时也兼容同名 `.png`、`.jpeg` 图片。没有图片时显示联系邮箱，不显示虚构二维码。

这里只展示静态图片，不接入支付接口，不识别付款，不解锁功能，不收集付款信息。付款在微信或支付宝中进行，由付款人核对收款人和金额。捐赠属于自愿支持，不构成软件商业分发授权。

本目录会包含在程序和公开源码中。只放准备公开的收款码，不放证件、付款记录、账户设置截图或其他个人资料。
