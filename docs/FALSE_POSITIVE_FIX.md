# 0.4.1 误遮挡修复

本次修正 0.4.0 在背景、手、身体和相邻镜头上出现额外遮挡的问题。预览优先、GPU 选项、分块缓存与画质导出流程保留。

## 改动

- 完整检测没有找到目标时，停止延续旧框。光流只用于快速档两次检测之间的画面，不再把上一个镜头的脸框延续到手、肩膀或身体。
- 跟踪特征点从面部内部选择，镜头变化判断更保守。
- 成功定位五官时使用面部轮廓，不再强行并入较大的椭圆。近似检测框也不再额外放大 20%；用户的覆盖范围只应用一次。
- 镜像、新增尺度、第二模型带来的额外候选必须验证。低置信度主检测候选会检查五官布局、多尺度一致性，必要时对局部裁剪运行另一个检测器。
- 局部裁剪中找到的脸必须与原候选重合，防止附近的真实人脸为一个落在手或肩膀上的错误框“背书”。
- 对画面边缘的部分脸保留有条件的通道，避免一次提高阈值就丢掉真实侧脸；失败候选列入人工复查。
- 缓存算法版本提升，0.4.0 的错误遮挡缓存不会直接复用。导入仍不自动分析，点击开始后按新规则重新识别。

## 验证

- 新增回归覆盖：目标移动或消失后没有遗留框、额外模型的未确认候选不被遮挡、保护确认面部下方的区域、邻近人脸不能确认错误候选，以及画面顶部的部分脸。
- 分块缓存、取消续跑和 CPU / GPU 解码对应帧一致性继续通过。分析回归共 8 项。
- 原有导出回归 6 组继续通过，包括短 4K60 / 1080p120、PCM 裁切、AAC、10 位 SDR、FFV1 逐像素比较和取消清理。
- 私人单人样片用于逐段回看及复查指定位置。视频、对比截图、输出文件和诊断数据留在本机，不随源码或安装包公开。

## 边界

更严格的候选复核可能漏掉部分低清晰度、遮挡或严重侧脸，仍需人工复查。快速档更偏向速度；不应将任何档位理解为零误检、零漏检。手如果真正挡在脸前，同一个面部遮挡区域仍可能覆盖手的重叠部分，本版没有做人体部位分割。覆盖范围设得过大也会扩大面部边缘。

本轮使用已有模型做验证，没有安装 AI 讨论稿中提出的新模型。
