# 模型

模型随源码整理包和便携包分发，运行不下载。本项目未训练模型。

- `face_landmarker.task`：Google MediaPipe 官方 float16 Face Landmarker：[下载来源](https://storage.googleapis.com/mediapipe-models/face_landmarker/face_landmarker/float16/latest/face_landmarker.task)。
- `face_detection_yunet_2026may.onnx`：OpenCV Zoo YuNet 动态输入模型，配合 OpenCV 5。[上游](https://github.com/opencv/opencv_zoo/tree/main/models/face_detection_yunet)，许可证在 `THIRD_PARTY/YuNet-LICENSE.txt`。
